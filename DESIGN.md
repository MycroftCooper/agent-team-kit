# Agent Team Kit UI

Adapted for an operational workbench from the [Linear analysis in awesome-design-md](https://github.com/VoltAgent/awesome-design-md/blob/fcc70284932276d085f01ef9f83edde90b1258cb/design-md/linear.app/DESIGN.md).

Use a near-black canvas, charcoal surfaces, hairline borders, and a sparse
lavender-blue primary action. Prefer compact lists, explicit state badges,
project context and a single My inbox for human decisions. Use system sans fonts
with Chinese fallbacks; no proprietary font or external font download is needed.

The reference's marketing layouts are not application layouts. This application
uses a persistent 226px sidebar, a 66px top bar, project filters, task lists and
detail dialogs. Typography is at least 11px for secondary metadata, 12–13px for
controls/body, and 20–33px for headings. Do not add hero imagery, gradients or
decorative charts. Status colors must carry meaning and remain accompanied by text.

Desktop checks cover 1440px and 1280px. Smaller screens collapse navigation and
stack cards. Dialogs trap focus, Escape dismisses, and N opens a new request when
focus is outside a field. Every form must preserve entered text during SSE updates.
