# v1.0 全链路演示（真实输出）

- 日期：2026-11-02 · 分支 `m0/baseline-and-p0`
- 脚本：`node scripts/v1-demo.mjs`（可重复执行；失败即抛错，不会静默通过）
- 环境：Windows 11 · Node 24.16 · 临时数据目录 + 随机端口 · MockRuntime（真实 DSH 不可用）

## 运行输出

```text
1. system up on http://127.0.0.1:5481 (schema v5, switchReadiness true)
2. seeded 3 tasks and 2 idle agents
3. scheduler dispatched, mock hosts executed: 2 COMPLETED of 2 run(s)
4. DEMO-T2 walked to REVIEWING (no automatic acceptance)
5. review PASS accepted (manifest hash + 24/24 tests), task -> INTEGRATING
6. human approval bound to the target hash -> DEMO-T2 = DONE
7. legacy CLI reads the same facts through the SQLite projection (export, read-only)
8. legacy CLI write refused with READ_ONLY_MODE (single fact source)

DEMO PASSED (8 steps)
```

## 每一步证明什么

| # | 步骤 | 证明 |
|---|---|---|
| 1 | `atk start` 起 backend/scheduler/2 hosts | 一条命令启动；schema 已迁移到 v5；`switchReadiness.ok=true`（空闲可切换） |
| 2 | 直接向 SQLite 播种 3 任务 + 2 Agent | 数据面可用；Agent 由 store 注册 |
| 3 | Scheduler 派发、Host 执行，2 个 Run `COMPLETED` | 派发→执行→状态推进链路真实跑通（不是库实例模拟） |
| 4 | Task 手动走到 `REVIEWING` | **M3 无自动验收**：Run 完成不会把 Task 推进到 DONE（已知限制，诚实暴露） |
| 5 | 评审 PASS（manifest hash + 24/24 证据） | 证据门槛生效：无 hash/测试不全无法 PASS |
| 6 | 人工验收绑定 target hash → `DONE` | `DONE` 唯一入口；approval 与候选 hash 绑定 |
| 7 | 旧 CLI `export` 读到同一批任务 | Phase C 只读投影成立（读 SQLite，不读 JSON） |
| 8 | 旧 CLI 写命令 → `READ_ONLY_MODE` | 单一写者原则成立：旧 CLI 不能再写 `state.json` |

## 复现方式

```powershell
node scripts/v1-demo.mjs          # 自动清理临时目录
node scripts/v1-demo.mjs --keep   # 保留数据目录便于检查
```

## 边界

- Agent 会话全部是 MockRuntime；真实 DSH 适配器仍然不可用（能力全 false）。
- 演示不覆盖浏览器 UI（需人工打开 `http://127.0.0.1:1421/`），Web 侧有单元测试与 headless 截图证据。
- 演示不覆盖备份/恢复（由 `m5-smoke` 与 `m6-smoke` 覆盖：篡改拒绝、精确行数、异地启动）。
