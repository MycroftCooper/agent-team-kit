# Quickstart

## Requirements

- Node.js **>= 20.11** (`node --version`). No other dependencies: the toolkit
  uses Node built-ins only.
- A project directory (git is optional; it helps, but the kit does not require
  commits).
- Optional: DeepSeek Harness, for the sidebar board panel.

## 60 seconds

```bash
# 1. make the CLI available (pick one)
npm install --global agent-team-kit
# or run without installing: npx agent-team-kit <command>
# or from a checkout:          node bin/atk.mjs <command>

# 2. scaffold the workflow in your project root
cd my-project
atk init --project my-app

# 3. look at what was written
atk board                    # renders <flowDir>/board.html
atk state check              # validate state.json
```

`atk init` is idempotent with `--force` and refuses to overwrite an existing
`agent-flow.config.json` without it. Preview it first:

```bash
atk init --project my-app --dry-run
atk init --project my-app --json        # machine report
atk init --project my-app --no-plugin   # skip the DSH board plugin copy
```

## What you get

```
agent-flow.config.json       project configuration
.agent-flow/
  state.json                 source of truth: batch, slices, packages
  ownership.json             path prefix -> role
  human-todos.json           things only the human can do
  runtime.json               who is working on what
  task-template.md           the 9-line ticket format
  commands.md                command cheat sheet
  current-batch.md           rolling notes for the current batch
  board.md                   rendered board (regenerated by atk)
  roles/<ROLE>.md            one role card per configured role
  README.md                  the entry point for agents
tools/agent-board/           copy of the DSH board plugin (unless --no-plugin)
```

Presets: `generic` (default: `LEAD,DEV,QA`, English, `.agent-flow/`) and
`p4deck` (an adoption layout for a project whose workflow already lives under a
custom directory: `LEAD,FE,BE,QA`, Chinese labels and paths).
Override flags: `--roles LEAD,DEV,QA --language en|zh-CN --flow-dir <dir>`.

## First batch

1. Edit `.agent-flow/state.json`: set `batch.goal` and `batch.stopCondition`, add
   slices (or keep it empty and let LEAD do it).
2. Open the board: `atk board`, or `atk serve` for live updates at
   `http://127.0.0.1:1421`.
3. Take a ticket as an agent:

   ```bash
   atk queue --for DEV
   atk task <ID> --for DEV --message
   ```

4. Run gates and derive status:

   ```bash
   atk gate fast --files <changed> --role DEV
   atk evidence
   atk board
   ```

## Install the agent skills

Copy [`../skills/agent-team-flow`](../skills/agent-team-flow/SKILL.md) and
[`../skills/agent-team-board`](../skills/agent-team-board/SKILL.md) into your
agent host's skills directory. See [`../skills/README.md`](../skills/README.md).

## Install the DSH panel (optional)

`atk init` already copied the plugin (unless `--no-plugin`). To install it:

1. DSH -> **Plugins** -> **Add plugin** -> **Install a third-party plugin**.
2. Paste the absolute path of `tools/agent-board`.
3. Enable it, merge the generated `cordis.patch.yml` `insert:` block into
   `~/.dsh/profiles/<profile>/cordis.patch.yml`, and restart DSH.

Details and troubleshooting: [BOARD.md](BOARD.md).
