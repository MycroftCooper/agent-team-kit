## 五、未修复/保留的边界（已知）

1. **多仓库场景**：Scheduler 目前以 `ATK_REPO_PATH` 或进程 cwd 取仓库；需要 snapshot 携带 `project.repoPath` 或 launcher 注入（单仓库 v1 成立）。
2. `runs.target_branch` 不再由 workspacePolicy 表达；若需记录集成分支，应由 backend 从 `project.defaultBranch` 落库（尚未实现，不阻塞验收）。
3. **worktree 清理**：smoke/launcher 运行会在 `%LOCALAPPDATA%\AgentTeamKit\worktrees` 留下注册（Host/workspace 负责清理，Scheduler 不负责）；建议后续加 prune。
4. 原子写 `.next` 仅在 rename 失败路径产生；极端同 mtime 场景可按内容优先，当前按 mtime 选最新。
5. Agent env scrub 依赖 adapter 尊重 `input.env`；真实 DSH adapter 必须配合（M7 前验证）。
6. 真实 DSH 仍不可用；MockRuntime 下验收。
