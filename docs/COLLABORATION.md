# 项目 Agent 与协作实况

每个 Agent 身份固定归属一个项目。凭据只能领取该项目的任务，并读取获准的项目计划、交付产物与资源。角色模板、小队配置和全局资源仍可共享；在不同项目使用同一角色时，需要分别创建身份。

## 创建和管理项目 Agent

选择工作空间，在「工作 → 协作实况」点击「管理项目 Agent」，或进入「团队 → 项目 Agent」。创建时绑定当前项目，团队由项目确定，归属不能改绑。撤销凭据会请求停止活动运行，文件锁仍需等停止确认或结束回执后才会释放。

项目 Agent 列表、概览、指派候选和协作快照都在后端按项目筛选。即使两个项目使用同一小队，身份也不能跨项目领取任务或读取项目产物。项目内的独立评审可以读取另一个执行身份的产物。

`atk-agent doctor` 返回身份的 `projectId`。领取请求省略 `projectId` 时使用凭据绑定的项目；显式指定不同项目会返回 `PROJECT_FORBIDDEN`。不需要额外配置项目环境变量。

小队的 `maxConcurrent` 继续作为共享小队的总并发上限；项目归属不会改变它原有的含义。Agent 的并发占用由活动和不确定 Run 计算。

## 协作实况

入口是「工作 → 协作实况」，概览也提供快捷入口。

- 「看 Agent」展示项目身份、角色、最近联系、容量占用，以及实际执行、规划或检查中的任务。已指派但尚未领取的工作单独标注。
- 「看工作拆分」展示需求与具体工作，并用任务名称表达前置依赖。
- 「正在跟进」可选择具体任务。选定后保持焦点，不会在任务通过检查时自动跳到其他任务。
- 最近活动显示已发生的领取、完成、评审、返工和验收。进度文字来自 Agent 上报，平台不会据此伪造完成百分比或内部思考。
- 人工任务单独显示。WORK 的可选评审、BUG 的直接修复和人工执行各自使用对应流转路径。

最近有联系不保证外部进程仍然存活，也不等于正在执行任务。运行被请求停止或隔离时，容量和文件占用仍需保留。已撤销但尚有未停止运行的身份也会保留在实况中。

页面用项目范围的 SSE 刷新，并在可见时每五秒补查联系状态。首次打开、恢复连接、切换项目或从后台返回时对齐最新快照，不播放补发的历史流转。新发生的状态变化用简短位移动画表达；可以关闭动画，也遵守系统的减少动态效果设置。

## 工作模块共用任务详情抽屉

在任务、Bug 单、待我处理、执行记录或协作实况点击任务名称，都通过工作台顶层入口展开同一个右侧抽屉。点其他任务会替换面板内容，不叠加多个任务面板。

抽屉是非模态面板，工作页面仍可操作。点击关闭或按 Esc 收起，保留当前页面、筛选和位置，并尽可能把焦点还给原入口。说明、验收条件、计划任务和交付记录可以分别折叠。技术 ID 留在详情的折叠区域。

任务与执行的链接仍可复制或直接打开；浏览器前进、后退继续恢复对应详情。切换项目会关闭旧项目详情。已开始的人工工作由工作台续租，不依赖抽屉或实况页面是否展开。

## 存量身份归属

服务启动时检查已有 Next 格式数据库中没有 `projectId` 的旧身份；不会导入更早版本的数据库格式：

1. 历史执行、计划作者和任务指派只涉及一个项目时，回填该项目。
2. 没有历史记录、且原小队只对应一个项目时，回填该项目。
3. 跨项目使用过、没有唯一候选或角色不兼容的身份，保留为待归属身份，不猜测归属，也不允许领取新任务。

待归属身份出现在「设置 → 旧 Agent 项目归属」。先确认所有活动或不确定运行已停止，再选择一个固定项目。需要用于其他项目时，分别创建新身份。历史 Run、交付、评审以及原身份引用均保留；不会自动清除文件锁。

旧凭据在迁移前仍可处理其已有运行的回执和停止确认。项目归属确定后，凭据立即受固定项目限制。项目已有未撤销身份时，需先撤销这些身份才能更换项目小队。

## 接口和验证

浏览器使用 `GET /api/v1/collaboration?projectId=...&planId=...` 读取只读快照。`planId` 可省略。快照包含项目身份、精简 Run、任务与依赖、最近进度、最近事件、服务时间和事件游标，不包含凭据、完整日志或文件快照。

方案选择显示最近 100 个方案；当前方案返回完整工作拆分，并补充最近 20 个 Bug 和所有活动运行关联任务。历史记录可在任务及执行记录页面继续查询。

Agent 管理接口必须明确项目范围：`GET /agents?projectId=...`、`GET /agents/:id?projectId=...`，更新和撤销也携带同一范围。创建请求必须提供 `projectId`。旧身份检查和归属由单用户设置页面的 `/agent-migrations`、`POST /agents/:id/bind` 处理。

运行 `node scripts/collaboration-e2e.mjs` 可验证真实领取与评审动画、项目切换、人工任务、设置中的旧身份归属，以及详情抽屉的跨页面复用和窄屏布局。测试证据保存在 `artifacts/collaboration-e2e`。
