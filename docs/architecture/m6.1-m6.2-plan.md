## 0. 写域矩阵（硬约束，防止并行冲突）

同一时刻**只有一个 owner** 可以改某个文件。跨包需求通过"契约先定、接口后写"解决。

| 文件/目录 | 唯一 owner | 谁**不得**直接改 |
|---|---|---|
| `apps/backend/src/routes-internal.mjs` | **WP2 (backend-runtime-api)** | WP1、WP3、WP4 |
| `apps/backend/src/server.mjs` | **WP1 (backend-core)** | WP2、WP3、WP4 |
| `apps/backend/src/auth.mjs`、`internal.mjs` | **WP1** | 其他 |
| `packages/database/**`（含 migrations） | **WP2 (database)** | WP1、WP3、WP5；WP4 只读 |
| `packages/contracts/**` | **Lead**（本计划作者） | 所有 worker |
| `apps/runtime-host/**` | **WP3 (runtime)** | WP1/WP2/WP4 |
| `packages/workspace/**` | **WP3**（M6.2 起） | 其他 |
| `apps/scheduler/**`、`packages/scheduler-core/**` | **WP4 (scheduler)** | 其他 |
| `apps/web/**` | **WP5 (frontend)** | 其他 |
| `test/**`（跨模块对抗套件） | **QA-01..05（qa-reviewer）** | 实现 agent 不写 QA 套件 |
| `scripts/*-smoke.mjs`、`docs/**` | **Lead** | 其他 |

**共享符号先冻结**：`applyRuntimeEventBatch`、`eventId`/`sessionSeq` 字段、`RuntimeHost` 心跳形状、`TaskExecutionSpec`、写域规则函数——先由 Lead / WP2 在契约层定形状，再各自实现。

   - WP3：F02/F09 的 **失败复现测试** + Outbox/原子恢复（等 ack 契约）
